# Bubble Tea CN 测试策略

## 概述

本文档定义了 Bubble Tea CN 项目的测试策略，包括单元测试、集成测试、系统测试的实施方法及测试工具使用规范。

## 测试类型

### 单元测试

单元测试是对最小可测试单元（函数、方法）的测试。

#### 测试原则

- 测试应该独立运行
- 测试应该快速执行
- 测试应该覆盖所有代码路径
- 测试应该易于理解和维护

#### 测试结构

```go
// 测试文件：tea_test.go
package tea

import (
    "testing"
)

func TestNewProgram(t *testing.T) {
    // 测试 NewProgram 函数
}

func TestProgram_Run(t *testing.T) {
    // 测试 Program.Run 方法
}
```

#### 测试示例

```go
func TestNewProgram(t *testing.T) {
    // 创建测试模型
    model := &testModel{}
    
    // 创建程序
    p := NewProgram(model)
    
    // 验证结果
    if p == nil {
        t.Fatal("NewProgram returned nil")
    }
    
    if p.initialModel != model {
        t.Errorf("initialModel not set correctly")
    }
}

func TestKeyString(t *testing.T) {
    tests := []struct {
        name string
        key  Key
        want string
    }{
        {
            name: "enter key",
            key:  Key{Type: KeyEnter},
            want: "enter",
        },
        {
            name: "escape key",
            key:  Key{Type: KeyEscape},
            want: "esc",
        },
        {
            name: "space key",
            key:  Key{Type: KeySpace},
            want: "space",
        },
    }
    
    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            if got := tt.key.String(); got != tt.want {
                t.Errorf("Key.String() = %v, want %v", got, tt.want)
            }
        })
    }
}
```

### 集成测试

集成测试是对多个组件协同工作的测试。

#### 测试原则

- 测试组件间的交互
- 测试数据流
- 测试错误处理
- 测试资源管理

#### 测试示例

```go
func TestProgram_Run_Integration(t *testing.T) {
    // 创建测试模型
    model := &testModel{
        quitAfter: 1,
    }
    
    // 创建程序
    p := NewProgram(model, 
        WithInput(strings.NewReader("q\n")),
        WithOutput(&bytes.Buffer{}),
    )
    
    // 运行程序
    finalModel, err := p.Run()
    
    // 验证结果
    if err != nil {
        t.Fatalf("Run() error = %v", err)
    }
    
    if finalModel == nil {
        t.Fatal("Run() returned nil model")
    }
}
```

### 系统测试

系统测试是对整个应用程序的测试。

#### 测试原则

- 测试完整的用户流程
- 测试性能指标
- 测试资源使用
- 测试错误恢复

#### 测试示例

```go
func TestProgram_CompleteWorkflow(t *testing.T) {
    // 模拟完整的用户交互流程
    input := "down\nenter\nq\n"
    
    model := &testModel{}
    p := NewProgram(model,
        WithInput(strings.NewReader(input)),
        WithOutput(&bytes.Buffer{}),
    )
    
    // 运行程序
    finalModel, err := p.Run()
    
    // 验证结果
    if err != nil {
        t.Fatalf("Run() error = %v", err)
    }
    
    // 验证最终状态
    if !finalModel.(*testModel).completed {
        t.Error("Workflow did not complete")
    }
}
```

## 测试工具

### Go Testing

Go 内置的测试框架。

#### 基本用法

```bash
# 运行所有测试
go test ./...

# 运行特定包的测试
go test ./tea

# 运行特定测试
go test -run TestNewProgram

# 显示详细输出
go test -v ./...

# 显示覆盖率
go test -cover ./...

# 生成覆盖率报告
go test -coverprofile=coverage.out ./...
go tool cover -html=coverage.out
```

#### 测试选项

| 选项 | 说明 |
|------|------|
| `-v` | 显示详细输出 |
| `-run` | 运行匹配的测试 |
| `-cover` | 显示覆盖率 |
| `-coverprofile` | 生成覆盖率报告 |
| `-race` | 检测竞态条件 |
| `-timeout` | 设置超时时间 |

### teatest

teatest 是专门用于测试 TUI 应用的工具。

#### 安装

```bash
go get github.com/purpose168/charm-experimental-packages-cn/exp/teatest
```

#### 基本用法

```go
import (
    "testing"
    "time"
    "github.com/purpose168/charm-experimental-packages-cn/exp/teatest"
)

func TestTeaTest(t *testing.T) {
    tm := teatest.NewTestModel(t, &testModel{}, teatest.WithInitialTermSize(80, 20))
    
    // 发送按键
    teatest.SendKey(tm, tea.KeyMsg{Type: tea.KeyEnter})
    
    // 等待更新
    teatest.WaitFor(t, tm.Output(), func(b []byte) bool {
        return bytes.Contains(b, []byte("Hello"))
    })
    
    // 获取最终模型
    finalModel := tm.FinalModel(t)
    
    // 验证结果
    if finalModel.(*testModel).count != 1 {
        t.Errorf("Expected count to be 1, got %d", finalModel.(*testModel).count)
    }
}
```

- 测试关键性能路径
- 测试资源使用

func BenchmarkRender(b *testing.B) {

## 并发测试

### 竞态条件检测

```bash
# 运行竞态条件检测
go test -race ./...
```

### 并发测试示例

```go
func TestConcurrentUpdate(t *testing.T) {
    model := &testModel{}
    
    done := make(chan bool)
    
    // 并发发送消息
    for i := 0; i < 10; i++ {
        go func() {
            msg := tea.KeyMsg{Type: tea.KeyEnter}
            model.Update(msg)
            done <- true
        }()
    }
    
    // 等待所有 goroutine 完成
    for i := 0; i < 10; i++ {
        <-done
    }
    
    // 验证结果
    if model.count != 10 {
        t.Errorf("Expected count to be 10, got %d", model.count)
    }
}
```

## 测试最佳实践

### 1. 表格驱动测试

使用表格驱动测试来测试多个用例：

```go
func TestKeyString(t *testing.T) {
    tests := []struct {
        name string
        key  Key
        want string
    }{
        {"enter", Key{Type: KeyEnter}, "enter"},
        {"escape", Key{Type: KeyEscape}, "esc"},
        {"space", Key{Type: KeySpace}, "space"},
    }
    
    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            if got := tt.key.String(); got != tt.want {
                t.Errorf("got %v, want %v", got, tt.want)
            }
        })
    }
}
```

### 2. 子测试

使用子测试来组织测试：

```go
func TestProgram(t *testing.T) {
    t.Run("NewProgram", func(t *testing.T) {
        // 测试 NewProgram
    })
    
    t.Run("Run", func(t *testing.T) {
        // 测试 Run
    })
    
    t.Run("Send", func(t *testing.T) {
        // 测试 Send
    })
}
```

### 3. 测试辅助函数

创建测试辅助函数来简化测试：

```go
func setupTestProgram(t *testing.T) (*Program, *bytes.Buffer) {
    t.Helper()
    
    model := &testModel{}
    output := &bytes.Buffer{}
    
    p := NewProgram(model,
        WithInput(strings.NewReader("q\n")),
        WithOutput(output),
    )
    
    return p, output
}

func TestWithHelper(t *testing.T) {
    p, output := setupTestProgram(t)
    
    // 运行程序
    p.Run()
    
    // 验证输出
    if output.Len() == 0 {
        t.Error("No output")
    }
}
```

## 总结

Bubble Tea CN 的测试策略全面而实用：

1. **单元测试**: 测试最小可测试单元
2. **集成测试**: 测试组件间交互
3. **系统测试**: 测试完整用户流程
4. **测试工具**: 使用专业的测试工具
5. **测试覆盖率**: 保持高覆盖率
6. **基准测试**: 测试性能指标
7. **并发测试**: 检测竞态条件
8. **最佳实践**: 遵循测试最佳实践

遵循这些测试策略可以确保代码质量和可靠性。
