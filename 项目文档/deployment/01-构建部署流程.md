# Bubble Tea CN 构建部署流程

## 概述

本文档提供了 Bubble Tea CN 项目的详细构建和部署流程，包括环境配置、构建步骤、部署流程及环境变量配置。

## 环境要求

### 开发环境

| 组件 | 版本 | 说明 |
|--------|--------|------|
| **Go** | 1.24.2+ | 编程语言 |
| **Git** | 2.0+ | 版本控制 |
| **Make** | 3.81+ | 构建工具（可选） |
| **Task** | 3.0+ | 任务运行器（可选） |

### 操作系统

- Linux (推荐)
- macOS
- Windows

### 终端要求

- 支持 ANSI 转义序列
- 支持 256 色或真彩色
- 推荐终端：xterm、iTerm2、Terminal.app、Windows Terminal

## 环境配置

### Go 环境配置

#### 安装 Go

```bash
# Linux
wget https://go.dev/dl/go1.24.2.linux-amd64.tar.gz
sudo tar -C /usr/local -xzf go1.24.2.linux-amd64.tar.gz

# 添加到 PATH
export PATH=$PATH:/usr/local/go/bin
echo 'export PATH=$PATH:/usr/local/go/bin' >> ~/.bashrc

# macOS
brew install go

# 验证安装
go version
```

#### 配置 Go Modules

```bash
# 启用 Go Modules（Go 1.16+ 默认启用）
go env -w GO111MODULE=on

# 设置代理（可选）
go env -w GOPROXY=https://goproxy.cn,direct
```

```bash
git clone https://github.com/purpose168/bubbletea-cn.git
cd bubbletea-cn
```

```bash

```

## 构建流程

### 本地构建

#### 构建命令

```bash
# 构建项目
go build -o bubbletea-cn ./...

# 构建特定平台

GOOS=darwin GOARCH=amd64 go build -o bubbletea-cn-darwin-amd64
GOOS=windows GOARCH=amd64 go build -o bubbletea-cn-windows-amd64.exe
```


## 部署流程

### 本地部署

#### 安装到系统

```bash
# 安装到 GOPATH
go install ./...

# 安装到 /usr/local/bin
sudo cp $GOPATH/bin/bubbletea-cn /usr/local/bin/

# 验证安装
bubbletea-cn --version
```

### Docker 部署

#### Dockerfile 示例

```dockerfile
# 构建阶段
FROM golang:1.24.2-alpine AS builder

WORKDIR /app

# 复制依赖文件
COPY go.mod go.sum ./
RUN go mod download

# 复制源代码
COPY . .

# 构建应用
RUN CGO_ENABLED=0 GOOS=linux go build -ldflags="-s -w" -o bubbletea-cn

# 运行阶段
FROM alpine:latest

WORKDIR /app

# 复制构建产物
COPY --from=builder /app/bubbletea-cn .

# 设置权限
RUN chmod +x bubbletea-cn

# 运行应用
CMD ["./bubbletea-cn"]
```

#### 构建和运行 Docker

```bash
# 构建镜像
docker build -t bubbletea-cn:latest .

# 运行容器
docker run -it --rm bubbletea-cn:latest

# 交互式运行
docker run -it --rm -e TERM=xterm-256color bubbletea-cn:latest
```

### 生产部署

#### 部署到 Linux 服务器

```bash
# 构建二进制文件
GOOS=linux GOARCH=amd64 go build -ldflags="-s -w" -o bubbletea-cn

# 上传到服务器
scp bubbletea-cn user@server:/usr/local/bin/

# 设置权限
ssh user@server "chmod +x /usr/local/bin/bubbletea-cn"

# 创建 systemd 服务
cat > /etc/systemd/system/bubbletea-cn.service << EOF
[Unit]
Description=Bubble Tea CN Application
After=network.target

[Service]
Type=simple
User=app
ExecStart=/usr/local/bin/bubbletea-cn
Restart=always
Environment=TERM=xterm-256color

[Install]
WantedBy=multi-user.target
EOF

# 启动服务
systemctl daemon-reload
systemctl enable bubbletea-cn
systemctl start bubbletea-cn
```

## CI/CD 配置

### GitHub Actions

#### .github/workflows/build.yml

```yaml
name: Build

on:
  push:
    branches: [ main, develop ]
  pull_request:
    branches: [ main ]

jobs:
  build:
    runs-on: ubuntu-latest
    
    steps:
    - uses: actions/checkout@v3
    
    - name: Set up Go
      uses: actions/setup-go@v4
      with:
        go-version: '1.24.2'
    
    - name: Install dependencies
      run: go mod download
    
    - name: Format check
      run: |
        go fmt ./...
        if [ -n "$(gofmt -l .)" ]; then
          echo "Go code is not formatted:"
          gofmt -d .
          exit 1
        fi
    
    - name: Vet
      run: go vet ./...
    
    - name: Test
      run: go test -v -cover ./...
    
    - name: Build
      run: go build -v ./...
```
