# Bubble Tea CN 项目架构概述

## 概述

Bubble Tea CN 是一个基于 [The Elm Architecture](https://guide.elm-lang.org/architecture/) 设计范式的 Go 语言 TUI（终端用户界面）框架。本项目是对 [Charmbracelet/Bubble Tea](https://github.com/charmbracelet/bubbletea) 的中文本地化衍生版本，保留了原始框架的核心功能，同时提供了中文文档和注释。

## 架构设计

### 核心架构模式

Bubble Tea 采用 **MVU（Model-View-Update）** 架构模式，这是一种函数式编程范式，与 Go 语言的设计理念高度契合。

#### MVU 架构三要素

```go
// Model 包含程序的状态以及其核心函数
type Model interface {
    // Init 是第一个被调用的函数，返回可选的初始命令
    Init() Cmd

    // Update 在收到消息时被调用，用于检查消息并更新模型
    Update(Msg) (Model, Cmd)

    // View 渲染程序的 UI，返回一个字符串
    View() string
}
```

1. **Model（模型）**: 表示应用程序的状态
2. **View（视图）**: 根据模型状态渲染 UI
3. **Update（更新）**: 处理消息并更新模型状态

## 核心组件

### 1. Program（程序）

Program 是 Bubble Tea 的核心结构，负责管理整个应用程序的生命周期。

```go
type Program struct {
    initialModel Model              // 初始模型
    msgs         chan Msg          // 消息通道
    errs         chan error        // 错误通道
    finished     chan struct{}      // 完成通道
    output       io.Writer        // 输出目标
    input        io.Reader        // 输入源
    renderer    renderer          // 渲染器
    ctx          context.Context   // 上下文
    cancel       context.CancelFunc // 取消函数
    // ... 其他配置字段
}
```

**职责**:
- 初始化和管理程序生命周期
- 处理用户输入和系统事件
- 协调消息传递和命令执行
- 管理终端状态（备用屏幕、鼠标模式等）
- 渲染 UI 到终端

### 2. Model（模型）

Model 是应用程序的状态容器，实现了三个核心方法。

```go
type Model interface {
    // Init 返回初始命令
    Init() Cmd

    // Update 处理消息并返回更新后的模型和命令
    Update(Msg) (Model, Cmd)

    // View 返回 UI 字符串
    View() string
}
```

**职责**:
- 存储应用程序状态
- 定义初始行为
- 处理消息并更新状态
- 生成 UI 表示

### 3. Msg（消息）

Msg 是任何类型，用于在应用程序中传递信息。

```go
type Msg interface{}
```

**常见消息类型**:
- `KeyMsg`: 键盘输入消息
- `MouseMsg`: 鼠标事件消息
- `WindowSizeMsg`: 窗口大小变化消息
- `QuitMsg`: 退出消息
- `TickMsg`: 定时器消息
- `FocusMsg`: 焦点获得消息
- `BlurMsg`: 焦点失去消息

### 4. Cmd（命令）

Cmd 是一个 I/O 操作，完成后返回一个消息。

```go
type Cmd func() Msg
```

**职责**:
- 执行异步 I/O 操作
- 返回结果消息
- 可以是 nil（无操作）

### 5. Renderer（渲染器）

Renderer 负责将 UI 渲染到终端。

```go
type renderer interface {
    start()                     // 启动渲染器
    stop()                       // 停止渲染器
    kill()                       // 终止渲染器
    write(string)                 // 写入帧
    repaint()                    // 请求重绘
    clearScreen()                // 清除屏幕
    altScreen() bool             // 是否在备用屏幕
    enterAltScreen()            // 进入备用屏幕
    exitAltScreen()             // 退出备用屏幕
    showCursor()                // 显示光标
    hideCursor()                // 隐藏光标
    enableMouseCellMotion()     // 启用鼠标单元格运动
    disableMouseCellMotion()    // 禁用鼠标单元格运动
    enableMouseAllMotion()     // 启用鼠标所有运动
    disableMouseAllMotion()    // 禁用鼠标所有运动
    enableMouseSGRMode()      // 启用鼠标 SGR 模式
    disableMouseSGRMode()     // 禁用鼠标 SGR 模式
    enableBracketedPaste()     // 启用括号粘贴
    disableBracketedPaste()    // 禁用括号粘贴
    bracketedPasteActive() bool // 括号粘贴是否激活
    setWindowTitle(string)      // 设置窗口标题
    reportFocus() bool         // 是否报告焦点
    enableReportFocus()       // 启用焦点报告
    disableReportFocus()      // 禁用焦点报告
    resetLinesRendered()     // 重置渲染行数
}
```

## 平台抽象

Bubble Tea 通过平台抽象层支持多个操作系统。

### Unix/Linux/macOS

```go
// tty_unix.go
type tty struct {
    file *os.File
    state *term.State
}

func openInputTTY() (term.File, error) {
    return term.Open("/dev/tty")
}

func (t *tty) Close() error {
    return t.file.Close()
}
```

### Windows

```go
// tty_windows.go
type tty struct {
    file *os.File
    state *term.State
}

func openInputTTY() (term.File, error) {
    return term.Open("CONIN$")
}

func (t *tty) Close() error {
    return t.file.Close()
}
```

## 配置选项

### ProgramOption

ProgramOption 用于在初始化程序时设置选项。

```go
type ProgramOption func(*Program)
```

**常用选项**:

| 选项 | 说明 |
|------|------|
| `WithContext(ctx)` | 设置运行上下文 |
| `WithOutput(w)` | 设置输出目标 |
| `WithInput(r)` | 设置输入源 |
| `WithInputTTY()` | 打开新的 TTY 输入 |
| `WithEnvironment(env)` | 设置环境变量 |
| `WithoutSignalHandler()` | 禁用信号处理器 |
| `WithoutCatchPanics()` | 禁用 panic 捕获 |
| `WithoutSignals()` | 忽略 OS 信号 |
| `WithAltScreen()` | 启用备用屏幕 |
| `WithMouseCellMotion()` | 启用鼠标单元格运动 |
| `WithMouseAllMotion()` | 启用鼠标所有运动 |
| `WithFPS(fps)` | 设置帧率 |

## 错误处理

### 错误类型

```go
var ErrProgramPanic = errors.New("program experienced a panic")
var ErrProgramKilled = errors.New("program was killed")
var ErrInterrupted = errors.New("program was interrupted")
```

### Panic 恢复

Bubble Tea 默认会捕获 panic 并恢复：

```go
if !p.startupOptions.has(withoutCatchPanics) {
    defer func() {
        if r := recover(); r != nil {
            p.recoverFromPanic(r)
        }
    }()
}
```

### 帧率控制

```go
// 设置帧率

```

### ANSI 压缩

```go
// 启用 ANSI 压缩以减少输出
p := tea.NewProgram(model, tea.WithANSICompressor())
```

### 增量渲染

Renderer 只渲染变化的部分，而不是整个屏幕：

```go
func (r *standardRenderer) write(str string) {
    // 只写入变化的部分
    r.buffer.WriteString(str)
    r.flush()
}
```

    }
    return m, nil

## 总结

Bubble Tea CN 的架构设计简洁而强大，基于 MVU 架构模式，提供了：

1. **清晰的关注点分离**: Model、View、Update 各司其职
2. **函数式编程**: 纯函数式更新，易于测试和推理
3. **消息驱动**: 通过消息传递实现组件间通信
4. **平台抽象**: 统一的接口支持多平台
5. **可扩展性**: 易于添加自定义消息、命令和渲染器

这种架构使得构建复杂而优雅的终端用户界面变得简单而愉悦。
