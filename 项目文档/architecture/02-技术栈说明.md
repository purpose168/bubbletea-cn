# Bubble Tea CN 技术栈说明

## 概述

Bubble Tea CN 是一个纯 Go 语言开发的 TUI 框架，采用函数式编程范式，基于 The Elm Architecture 设计。本文档详细说明了项目使用的技术组件及其版本信息。

## 终端特性

### ANSI 转义序列

Bubble Tea 使用 ANSI 转义序列与终端交互：

| 功能 | ANSI 序列 | 用途 |
|--------|-----------|------|
| **备用屏幕** | `\x1b[?1049h` | 进入备用屏幕缓冲区 |
| **光标隐藏** | `\x1b[?25l` | 隐藏光标 |
| **光标显示** | `\x1b[?25h` | 显示光标 |
| **鼠标启用** | `\x1b[?1000h` | 启用鼠标跟踪 |
| **括号粘贴** | `\x1b[?2004h` | 启用括号粘贴模式 |
| **焦点报告** | `\x1b[?1004h` | 启用焦点事件报告 |

### 终端模式

| 模式 | 说明 | 使用场景 |
|------|------|---------|
| **Raw Mode** | 原始模式，禁用行缓冲和回显 | 交互式应用 |
| **Alternate Screen** | 备用屏幕缓冲区 | 全屏应用 |
| **Bracketed Paste** | 括号粘贴模式 | 文本输入 |
| **Mouse Tracking** | 鼠标跟踪 | 鼠标交互 |

## 安全性

### 输入验证

Bubble Tea 不执行用户输入，所有输入都通过 Model.Update 处理：

```go
func (m model) Update(msg tea.Msg) (tea.Model, tea.Cmd) {
    switch msg := msg.(type) {
    case tea.KeyMsg:
        // 安全地处理键盘输入
        return m, nil
    }
    return m, nil
}
```

### Panic 恢复

默认启用 panic 恢复，确保终端状态正确恢复：

```go
defer func() {
    if r := recover(); r != nil {
        p.recoverFromPanic(r)
    }
}()
```

## 总结

Bubble Tea CN 的技术栈简洁而强大：

1. **纯 Go 实现**: 无外部语言依赖
2. **跨平台**: 支持 Linux、macOS、Windows
3. **最小依赖**: 只依赖必要的库
4. **高性能**: 优化的渲染和并发处理
5. **生产就绪**: 在多个大型项目中使用

这种技术栈选择使得 Bubble Tea CN 成为一个可靠、高效且易于维护的 TUI 框架。
