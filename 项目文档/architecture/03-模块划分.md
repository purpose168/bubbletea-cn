# Bubble Tea CN 模块划分

## 概述

Bubble Tea CN 项目采用模块化设计，将功能划分为清晰的模块，每个模块负责特定的职责。本文档详细说明了项目的模块划分及其职责。

## 核心模块

### 1. Program 模块

**文件**: `tea.go`

**职责**:
- 管理程序生命周期
- 处理事件循环
- 协调消息传递
- 管理终端状态
- 渲染 UI

**核心结构**:
```go
type Program struct {
    initialModel Model              // 初始模型
    msgs         chan Msg          // 消息通道
    errs         chan error        // 错误通道
    finished     chan struct{}      // 完成通道
    output       io.Writer        // 输出目标
    input        io.Reader        // 输入源
    renderer    renderer          // 渲染器
    ctx          context.Context   // 上下文
    cancel       context.CancelFunc // 取消函数
    // ... 其他配置字段
}
```

**主要方法**:
- `NewProgram(model, opts...)` - 创建新程序
- `Run()` - 运行程序
- `Send(msg)` - 发送消息到程序
- `Quit()` - 退出程序

### 2. Model 模块

**文件**: `tea.go`

**职责**:
- 定义应用程序状态
- 实现初始化逻辑
- 处理消息更新
- 生成 UI 视图

**接口定义**:
```go
type Model interface {
    // Init 返回初始命令
    Init() Cmd

    // Update 处理消息并返回更新后的模型和命令
    Update(Msg) (Model, Cmd)

    // View 返回 UI 字符串
    View() string
}
```

### 4. Cmd 模块

**文件**: `commands.go`

**职责**:
- 定义命令类型
- 执行异步操作
- 返回结果消息

**核心命令**:

| 命令 | 说明 | 文件 |
|------|------|------|
| `Quit()` | 退出命令 | `tea.go` |
| `Suspend()` | 暂停命令 | `tea.go` |
| `Interrupt()` | 中断命令 | `tea.go` |
| `Batch(cmds...)` | 批量执行命令 | `commands.go` |
| `Sequence(cmds...)` | 顺序执行命令 | `commands.go` |
| `Every(duration, fn)` | 定时器命令 | `commands.go` |
| `Tick(duration, fn)` | 单次定时命令 | `commands.go` |
| `Exec(cmd, fn)` | 执行外部命令 | `exec.go` |
| `ExecProcess(cmd, fn)` | 执行进程命令 | `exec.go` |

### 5. Renderer 模块

**文件**: `renderer.go`, `standard_renderer.go`, `nil_renderer.go`

**职责**:
- 渲染 UI 到终端
- 管理终端状态
- 处理 ANSI 转义序列
- 优化渲染性能

**接口定义**:
```go
type renderer interface {
    start()                       // 启动渲染器
    stop()                         // 停止渲染器
    kill()                         // 终止渲染器
    write(string)                   // 写入帧
    repaint()                      // 请求重绘
    clearScreen()                  // 清除屏幕
    altScreen() bool                // 是否在备用屏幕
    enterAltScreen()                // 进入备用屏幕
    exitAltScreen()                 // 退出备用屏幕
    showCursor()                   // 显示光标
    hideCursor()                   // 隐藏光标
    enableMouseCellMotion()         // 启用鼠标单元格运动
    disableMouseCellMotion()        // 禁用鼠标单元格运动
    enableMouseAllMotion()         // 启用鼠标所有运动
    disableMouseAllMotion()        // 禁用鼠标所有运动
    enableMouseSGRMode()          // 启用鼠标 SGR 模式
    disableMouseSGRMode()         // 禁用鼠标 SGR 模式
    enableBracketedPaste()         // 启用括号粘贴
    disableBracketedPaste()        // 禁用括号粘贴
    bracketedPasteActive() bool     // 括号粘贴是否激活
    setWindowTitle(string)          // 设置窗口标题
    reportFocus() bool             // 是否报告焦点
    enableReportFocus()           // 启用焦点报告
    disableReportFocus()          // 禁用焦点报告
    resetLinesRendered()         // 重置渲染行数
}
```

**实现类型**:
- `standardRenderer` - 标准渲染器，支持所有功能
- `nilRenderer` - 空渲染器，用于测试

- `MouseButtonWheelUp` - 滚轮向上

| `WithEnvironment(env)` | `ProgramOption` | 设置环境变量 |

| `WithoutSignals()` | `ProgramOption` | 忽略 OS 信号 |

| `WithMouseCellMotion()` | `ProgramOption` | 启用鼠标单元格运动 |
| `WithMouseAllMotion()` | `ProgramOption` | 启用鼠标所有运动 |
| `WithFPS(fps)` | `ProgramOption` | 设置帧率 |
| `WithANSICompressor()` | `ProgramOption` | 启用 ANSI 压缩 |
| `WithFilter(fn)` | `ProgramOption` | 设置消息过滤器 |

## 模块交互

### 初始化流程

```
1. NewProgram(model, opts...)
    │
    ├── 应用 ProgramOption
    │
    ├── 创建消息通道
    │
    ├── 创建渲染器
    │
    └── 初始化上下文
```

### 运行流程

```
1. Program.Run()
    │
    ├── 初始化终端
    │
    ├── 启动渲染器
    │
    ├── 调用 model.Init()
    │
    ├── 启动事件循环
    │
    ├── 处理输入
    │
    ├── 处理消息
    │
    ├── 渲染视图
    │
    └── 清理资源
```

## 总结

Bubble Tea CN 的模块划分清晰而合理：

1. **职责分离**: 每个模块有明确的职责
2. **低耦合**: 模块间通过接口交互
3. **高内聚**: 相关功能集中在同一模块
4. **易于扩展**: 可以轻松添加新模块
5. **易于测试**: 模块可以独立测试

这种模块化设计使得 Bubble Tea CN 成为一个易于理解、维护和扩展的 TUI 框架。
