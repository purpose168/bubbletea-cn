# Bubble Tea CN 数据流程文档

## 概述

本文档详细说明了 Bubble Tea CN 框架中关键业务流程的数据流转，包括初始化流程、事件处理流程、渲染流程等。

## 初始化流程

### 程序创建流程

```
用户代码
    │
    ▼
NewProgram(model, opts...)
    │
    ├── 应用 ProgramOption
    │
    ├── 创建消息通道 (msgs)
    │
    ├── 创建错误通道 (errs)
    │
    ├── 创建完成通道 (finished)
    │
    ├── 创建上下文 (ctx, cancel)
    │
    ├── 设置输出目标 (output)
    │
    ├── 设置输入源 (input)
    │
    ├── 创建渲染器 (renderer)
    │
    └── 返回 Program 实例
```

### 代码示例

```go
// 创建程序
p := tea.NewProgram(initialModel(),
    tea.WithAltScreen(),
    tea.WithMouseCellMotion(),
    tea.WithFPS(60),
)

// 内部实现
func NewProgram(model Model, opts ...ProgramOption) *Program {
    p := &Program{
        initialModel: model,
        msgs:         make(chan Msg),
        // ... 其他初始化
    }
    
    // 应用所有选项
    for _, opt := range opts {
        opt(p)
    }
    
    return p
}
```

## 运行流程

### 程序启动流程

```
p.Run()
    │
    ├── 初始化终端
    │
    ├── 启动渲染器
    │
    ├── 调用 model.Init()
    │
    ├── 渲染初始视图
    │
    ├── 启动事件循环
    │
    │   ├── 处理输入
    │   │
    │   ├── 处理消息
    │   │
    │   ├── 执行命令
    │   │
    │   └── 渲染视图
    │
    └── 清理资源
```

### 代码示例

```go
func (p *Program) Run() (returnModel Model, returnErr error) {
    // 1. 初始化终端
    if err := p.initTerminal(); err != nil {
        return p.initialModel, err
    }
    
    // 2. 启动渲染器
    p.renderer.start()
    
    // 3. 初始化模型
    model := p.initialModel
    if initCmd := model.Init(); initCmd != nil {
        // 发送初始命令
        cmds <- initCmd
    }
    
    // 4. 渲染初始视图
    p.renderer.write(model.View())
    
    // 5. 启动事件循环
    model, err := p.eventLoop(model, cmds)
    
    // 6. 清理资源
    p.shutdown(killed)
    
    return model, err
}
```

## 事件处理流程

### 事件循环流程

```
事件循环 (eventLoop)
    │
    ├── 等待事件
    │
    ├── 接收消息
    │
    ├── 过滤消息
    │
    ├── 处理特殊消息
    │
    ├── 调用 model.Update()
    │
    ├── 发送命令
    │
    └── 渲染视图
```

### 消息处理流程

```
接收消息 (msgs channel)
    │
    ▼
┌──────────────────┐
│  消息过滤      │
│  (filter)       │
└──────────────────┘
    │
    ▼
┌──────────────────┐
│  特殊消息处理    │
│  (switch msg)   │
└──────────────────┘
    │
    ├── QuitMsg → 退出
    ├── InterruptMsg → 中断
    ├── SuspendMsg → 暂停
    ├── WindowSizeMsg → 调整大小
    ├── FocusMsg → 焦点处理
    ├── BlurMsg → 焦点处理
    ├── KeyMsg → 键盘处理
    ├── MouseMsg → 鼠标处理
    └── 其他 → 用户处理
    │
    ▼
┌──────────────────┐
│  model.Update() │
│  用户代码处理    │
└──────────────────┘
    │
    ▼
返回 (newModel, cmd)
```

### 代码示例

```go
func (p *Program) eventLoop(model Model, cmds chan Cmd) (Model, error) {
    for {
        select {
        case <-p.ctx.Done():
            return model, nil
        
        case err := <-p.errs:
            return model, err
        
        case msg := <-p.msgs:
            // 过滤消息
            if p.filter != nil {
                msg = p.filter(model, msg)
            }
            if msg == nil {
                continue
            }
            
            // 处理特殊消息
            switch msg := msg.(type) {
            case QuitMsg:
                return model, nil
            
            case InterruptMsg:
                return model, ErrInterrupted
            
            case SuspendMsg:
                if suspendSupported {
                    p.suspend()
                }
            }
            
            // 处理用户消息
            var cmd Cmd
            model, cmd = model.Update(msg)
            
            // 发送命令
            select {
            case <-p.ctx.Done():
                return model, nil
            case cmds <- cmd:
            }
            
            // 渲染视图
            p.renderer.write(model.View())
        }
    }
}
```

## 渲染流程

### 视图生成流程

```
Model 状态
    │
    ▼
model.View()
    │
    ├── 读取状态
    │
    ├── 生成 UI 字符串
    │
    ├── 应用样式
    │
    └── 返回字符串
```

### 渲染器写入流程

```
View() 返回的字符串
    │
    ▼
renderer.write(str)
    │
    ├── 检查变化
    │
    ├── 更新缓冲区
    │
    ├── 压缩 ANSI 序列
    │
    └── 写入终端
```

### 代码示例

```go
// 模型视图
func (m model) View() string {
    s := "Hello, Bubble Tea!\n\n"
    s += "Press q to quit.\n"
    return s
}

// 渲染器写入
func (r *standardRenderer) write(str string) {
    // 检查是否需要重绘
    if r.needsRepaint {
        r.buffer.WriteString(str)
        r.flush()
        r.needsRepaint = false
    } else {
        // 增量渲染
        r.buffer.WriteString(str)
    }
}
```

## 命令执行流程

### 命令处理流程

```
命令通道 (cmds channel)
    │
    ▼
┌──────────────────┐
│  命令处理器     │
│  handleCommands  │
└──────────────────┘
    │
    ├── 接收命令
    │
    ├── 执行命令 (goroutine)
    │
    ├── 捕获 panic
    │
    └── 发送结果消息
```

### 批量命令流程

```
Batch(cmd1, cmd2, cmd3)
    │
    ▼
┌──────────────────┐
│  compactCmds   │
│  压缩命令      │
└──────────────────┘
    │
    ├── 过滤 nil 命令
    │
    ├── 返回单个命令或批量命令
    │
    └── 并发执行
```

### 代码示例

```go
// 批量命令
func (m model) Init() tea.Cmd {
    return tea.Batch(
        tea.EnterAltScreen(),
        tea.EnableMouseCellMotion(),
        tea.ShowCursor(),
    )
}

// 命令处理器
func (p *Program) handleCommands(cmds chan Cmd) chan struct{} {
    ch := make(chan struct{})
    
    go func() {
        defer close(ch)
        
        for {
            select {
            case <-p.ctx.Done():
                return
            
            case cmd := <-cmds:
                if cmd == nil {
                    continue
                }
                
                go func() {
                    defer func() {
                        if r := recover(); r != nil {
                            p.recoverFromPanic(r)
                        }
                    }()
                    
                    msg := cmd()
                    p.Send(msg)
                }()
            }
        }
    }()
    
    return ch
}
```

## 终端管理流程

### 终端初始化流程

```
程序启动
    │
    ▼
┌──────────────────┐
│  initTerminal   │
│  终端初始化     │
└──────────────────┘
    │
    ├── 打开 TTY
    │
    ├── 设置原始模式
    │
    ├── 隐藏光标
    │
    ├── 启用备用屏幕（如果配置）
    │
    ├── 启用鼠标（如果配置）
    │
    └── 保存终端状态
```

### 终端清理流程

```
程序退出
    │
    ▼
┌──────────────────┐
│  shutdown      │
│  清理资源       │
└──────────────────┘
    │
    ├── 恢复终端状态
    │
    ├── 显示光标
    │
    ├── 退出备用屏幕（如果激活）
    │
    ├── 禁用鼠标（如果激活）
    │
    ├── 关闭 TTY
    │
    └── 等待所有处理器完成
```

### 代码示例

```go
// 初始化终端
func (p *Program) initTerminal() error {
    // 检查输出是否为 TTY
    if term.IsTerminal(p.output) {
        p.ttyOutput = p.output.(term.File)
        state, err := term.MakeRaw(p.ttyOutput.Fd())
        if err != nil {
            return err
        }
        p.previousOutputState = state
    }
    
    // 检查输入是否为 TTY
    if term.IsTerminal(p.input) {
        p.ttyInput = p.input.(term.File)
        state, err := term.MakeRaw(p.ttyInput.Fd())
        if err != nil {
            return err
        }
        p.previousTtyInputState = state
    }
    
    return nil
}

// 清理资源
func (p *Program) shutdown(killed bool) {
    // 恢复终端状态
    if p.previousOutputState != nil {
        p.previousOutputState.Restore()
    }
    
    if p.previousTtyInputState != nil {
        p.previousTtyInputState.Restore()
    }
    
    // 停止渲染器
    if killed {
        p.renderer.kill()
    } else {
        p.renderer.stop()
    }
    
    // 等待所有处理器
    p.handlers.shutdown()
}
```

## 窗口大小变化流程

### 窗口大小检测流程

```
终端窗口大小变化
    │
    ▼
┌──────────────────┐
│  handleResize  │
│  处理窗口大小   │
└──────────────────┘
    │
    ├── 监听 SIGWINCH 信号（Unix）
    │
    ├── 查询终端大小
    │
    ├── 生成 WindowSizeMsg
    │
    └── 发送到消息通道
```

### 代码示例

```go
// 处理窗口大小变化
func (p *Program) handleResize() chan struct{} {
    ch := make(chan struct{})
    
    if p.ttyOutput != nil {
        // 获取初始大小
        go p.checkResize()
        
        // 监听窗口大小变化
        go p.listenForResize(ch)
    } else {
        close(ch)
    }
    
    return ch
}

// 检查窗口大小
func (p *Program) checkResize() {
    width, height, err := term.GetSize(p.ttyOutput.Fd())
    if err != nil {
        return
    }
    
    p.Send(WindowSizeMsg{
        Width:  width,
        Height: height,
    })
}

// 监听窗口大小变化
func (p *Program) listenForResize(ch chan struct{}) {
    sig := make(chan os.Signal, 1)
    signal.Notify(sig, syscall.SIGWINCH)
    defer signal.Stop(sig)
    
    for {
        select {
        case <-p.ctx.Done():
            close(ch)
            return
        
        case <-sig:
            p.checkResize()
        }
    }
}
```

## 焦点管理流程

```
终端焦点变化
    │
    ▼
┌──────────────────┐
│  焦点事件       │
└──────────────────┘
    │
    ├── 终端获得焦点
    │
    ├── 生成 FocusMsg
    │
    ├── 终端失去焦点
    │
    ├── 生成 BlurMsg
    │
    └── 发送到消息通道
```

### 代码示例

```go
// 启用焦点报告
func (r *standardRenderer) enableReportFocus() {
    r.reportFocus = true
    // 发送 ANSI 转义序列启用焦点报告
    r.tty.WriteString("\x1b[?1004h")
}

// 处理焦点事件
func (r *standardRenderer) handleMessages(msg tea.Msg) {
    switch msg := msg.(type) {
    case tea.FocusMsg:
        // 终端获得焦点
        r.hasFocus = true
    
    case tea.BlurMsg:
        // 终端失去焦点
        r.hasFocus = false
    }
}
```

## 总结

Bubble Tea CN 的数据流程清晰而高效：

1. **单向数据流**: 消息单向流动，易于理解和调试
2. **异步处理**: 命令异步执行，不阻塞主循环
3. **事件驱动**: 所有操作都由事件触发
4. **状态隔离**: Model 状态完全隔离，纯函数式更新
5. **资源管理**: 终端状态自动管理，确保正确清理

这种数据流设计使得 Bubble Tea CN 成为一个可靠、高效且易于理解的 TUI 框架。
